# meta-ads-niche-report

Скилл для Claude, который собирает активную рекламу конкурентов из
**Библиотеки рекламы Meta** (Facebook/Instagram) по нише и городу и
превращает её в отчёт для таргетолога: кто рекламируется, куда ведёт
реклама (Директ, профиль Instagram, сайт, WhatsApp, Telegram), какие
офферы и хуки повторяются у разных рекламодателей, какие объявления крутятся
дольше всех и какие углы почти никто не использует. Без платных API.

English version: [README.md](README.md)

## Пример отчёта

[examples/sample-report.md](examples/sample-report.md) — полный пример
отчёта с вымышленными названиями рекламодателей и придуманными цифрами,
показывающий формат из 8 разделов, который генерирует скилл.

## Как это работает

Библиотека рекламы (`facebook.com/ads/library`) открывается без логина.
Объявления приходят двумя путями: JSON, встроенный в страницу при первой
загрузке, и ответы `graphql` при прокрутке или новом поиске.
[`scripts/collector.js`](plugins/meta-ads-niche-report/skills/meta-ads-niche-report/scripts/collector.js)
перехватывает оба пути целиком на стороне клиента — ничего платного, никакой
регистрации. Этот файл — единственный источник логики сбора и агрегатов; оба
режима ниже вызывают его как есть.

Есть два режима запуска, скилл сам выбирает между ними:

1. **Браузерный режим** — если в сессии Claude уже есть инструмент браузера
   (встроенный браузер Cowork, Claude in Chrome и т.п.), он управляет
   Библиотекой прямо в браузере. См.
   [references/browser-mode.md](plugins/meta-ads-niche-report/skills/meta-ads-niche-report/references/browser-mode.md).
2. **CLI-режим** — [`scripts/scrape.py`](plugins/meta-ads-niche-report/skills/meta-ads-niche-report/scripts/scrape.py)
   управляет настоящим Chromium через Playwright. Полезен в Claude Code, где
   есть shell, но нет инструмента браузера.

Из облачных контейнеров `facebook.com` сразу отдаёт `403` — это работает
только из среды с обычным, не датацентровым сетевым путём (собственная
машина пользователя или сессия с настоящим инструментом браузера).

## Установка

### claude.ai / Cowork

Заархивируй папку скилла —
`plugins/meta-ads-niche-report/skills/meta-ads-niche-report/` — и загрузи
zip через **Settings → Skills → Upload skill**.

### Claude Code

Либо:
- скопируй `plugins/meta-ads-niche-report/skills/meta-ads-niche-report/` в
  `~/.claude/skills/meta-ads-niche-report/`, либо
- добавь этот репозиторий как плагин-маркетплейс и установи из него:
  ```text
  /plugin marketplace add YanisDigital/competitor-ads
  /plugin install meta-ads-niche-report@meta-ads-niche-report
  ```

## Требования

- **Браузерный режим**: инструмент браузера в сессии Claude (встроенный
  браузер, Claude in Chrome и т.п.) — ничего устанавливать не нужно.
- **CLI-режим**: Python 3.10+ и [Playwright](https://playwright.dev/python/):
  ```bash
  pip install playwright
  python -m playwright install chromium
  ```
  Ни скилл, ни тесты этого репозитория не устанавливают их автоматически —
  ты ставишь их сам, когда реально собираешься собирать данные.

## Ограничения

- Анализируется только **текст** объявления (заголовок, тело, CTA, ссылка),
  а не содержимое картинок/видео креатива.
- Отчёт — это **снимок на момент запуска**; рекламный инвентарь Meta меняется
  ежедневно.
- Вне ЕС Meta не показывает бюджет и охват коммерческой рекламы, поэтому
  «сила» рекламодателя видна только косвенно — по числу объявлений и
  длительности показа.
- Поиск ищет по **тексту** объявления, а не по гео рекламодателя — название
  города должно быть в самом объявлении, чтобы попасть в выборку по запросу
  с этим городом.

## Дисклеймер

> **Это инструмент для исследования публично доступных рекламных данных.**
> Библиотека рекламы Meta открывается без логина, но автоматический сбор
> данных из неё может противоречить условиям использования (Terms of
> Service) Meta. Ответственность за использование инструмента и соблюдение
> применимого законодательства — в том числе законов о защите данных
> (например, GDPR), если ты работаешь с найденными через него личными
> контактами — лежит на пользователе. Проект не связан с Meta или Anthropic,
> не одобрен и не поддерживается ими.
>
> Инструменты в этом репозитории осознанно никогда не логинятся, не
> используют чужие сессии/куки, не обходят капчу и не ротируют прокси и не
> подделывают отпечаток браузера. Если Библиотека показывает стену логина
> или капчу, оба режима сбора останавливаются сами, а не пытаются это
> обойти — см.
> [references/troubleshooting.md](plugins/meta-ads-niche-report/skills/meta-ads-niche-report/references/troubleshooting.md).
