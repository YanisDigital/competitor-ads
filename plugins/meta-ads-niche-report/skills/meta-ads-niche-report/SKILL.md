# Отчёт по рекламе конкурентов в нише (Meta Ads Library)

Задача: за один прогон собрать активные объявления ниши в городе и превратить их в отчёт, по которому таргетолог строит оффер и креативы для клиента. Ценность не в выгрузке, а в выводах: куда ведут воронки, что обещают все, что крутится дольше всего и о чём не говорит никто.

## Почему через встроенный браузер

Из облачного контейнера facebook.com отдаёт 403, а headless-скрейперы Meta быстро блокирует. Встроенный браузер (инструменты `mcp__remote-devices__Claude_Browser__*`) открывает Библиотеку как обычный пользователь без логина. Страница сама грузит JSON с объявлениями, а скрипт ниже его перехватывает. Ничего не нужно устанавливать.

Загрузи инструменты одним вызовом: `ToolSearch` с запросом `mcp__remote-devices__Claude_Browser__`, `max_results: 64`. Если браузер недоступен, скажи об этом пользователю и остановись: обходных путей через curl нет.

## Шаг 1. Параметры

- **Ниша** (обязательно) и **город** (обязательно для локального бизнеса).
- **Страна**: по умолчанию `UA`.
- Только активные объявления (по умолчанию да).
- CSV-выгрузка: только если попросили.

Если ниша или город не названы и контекст их не подсказывает, спроси одним вопросом.

## Шаг 2. Список поисковых запросов

Поиск Библиотеки ищет по **тексту объявления**, а не по гео рекламодателя. Одно ключевое слово ловит малую часть рынка, поэтому составь 6–12 запросов:

- 3–6 услуг/подниш (для бьюти: салон краси, манікюр, косметолог, епіляція, вії, брови; для стоматологии: стоматологія, імплантація, брекети, вініри);
- каждую — по-украински и по-русски;
- с городом в обоих написаниях (Одеса / Одесса), для крупных сетей можно и без города.

Покажи список пользователю одной строкой и сразу продолжай.

## Шаг 3. Открыть первый запрос и установить сборщик

Открой вкладку через `preview_start` со ссылкой:

```
https://www.facebook.com/ads/library/?active_status=active&ad_type=all&country=UA&q=<URL-кодированный запрос>&search_type=keyword_unordered&media_type=all
```

Сразу выполни в этой вкладке (`javascript_tool`) скрипт-сборщик **целиком, без изменений**. Перед ним поставь `await new Promise(r=>setTimeout(r,3000));`, чтобы страница успела загрузиться. Скрипт перехватывает ответы страницы, поэтому его нужно ставить заново после каждой полной перезагрузки. Он возвращает `installed: N ads buffered`.

## Шаг 4. Сбор по каждому запросу

**Не используй `navigate` между запросами.** Перезагрузка стирает сборщик и всё собранное. Новый запрос вводи в поле поиска на той же странице: это SPA, данные подгружаются без перезагрузки.

Для первого запроса (уже открыт):
```javascript
await window.__mai.scroll(6); window.__mai.collect('<запрос>')
```

Для каждого следующего одним `browser_batch`:
1. `find` → «Search by keyword» (нужен ref текстового поля; после первого раза можно кликать по его координатам);
2. `computer triple_click` по полю → `key ctrl+a` → `type <запрос>` → `key Return` → `wait 4`;
3. `javascript_tool`: `await window.__mai.scroll(6); window.__mai.collect('<запрос>')`.

Ограничения, из-за которых так построено:
- у `browser_batch` лимит около 50 секунд, поэтому **один запрос на один batch**;
- прокручивай только через `__mai.scroll`, а не через `computer scroll`: последний зависает;
- `collect` возвращает `captured` и `library_says`. Если `captured` заметно меньше `library_says`, вызови ещё раз `await window.__mai.scroll(6); window.__mai.collect(...)`. Небольшой разрыв нормален: Библиотека считает варианты одного объявления отдельно;
- `captured: 0` и пустой `library_says` означают, что по запросу ничего нет. Двигайся дальше.

## Шаг 5. Чистка и агрегаты

Посмотри `window.__mai.report().top_pages` и выброси явно чужих рекламодателей: недвижимость, случайные совпадения слов, при желании — школы и курсы для мастеров (это не конкуренты салона, их можно дать отдельным абзацем):
```javascript
window.__mai.exclude(['Название страницы 1', 'Название страницы 2'])
```
Затем получи агрегаты:
```javascript
JSON.stringify(window.__mai.report({longDays: 90}))
```
В ответе: `ads`, `advertisers`, `single_ad_advertisers`, `doors` (куда ведёт реклама), `ctas`, `platforms`, `formats`, `age_buckets`, `hook_freq` (сколько объявлений упоминают цену, скидку, гарантию, рассрочку и т.д.), `top_pages` (объявления, возраст, двери, свои сайты), `longrun` (самые старые объявления), `samples` (по одному тексту на рекламодателя).

## Шаг 6 (по желанию). Сайты лидеров

Для 3–5 крупнейших рекламодателей со своим сайтом открой сайт в новой вкладке (`preview_start`) и прочитай `get_page_text`: первый экран, главный посыл, цены. Это даёт раздел «Расхождения реклама vs сайт» и реальные цены ниши. Пропускай шаг, если пользователь просил быстрый срез.

## Шаг 7. Отчёт в чате

Используй эту структуру. Цифры бери из `report()`, выводы делай сам: в них вся ценность.

1. **Сводка**: ниша, город, число запросов, N объявлений от M рекламодателей, сколько рекламодателей с одним объявлением, доля объявлений младше 30 дней, платформы, форматы.
2. **Кто рекламируется**: таблица топ-10 (страница · объявлений · самое старое, дней · куда ведёт · сайт).
3. **Куда ведёт реклама**: доли дверей и вывод, какой формат воронки норма для ниши.
4. **Что обещают и какие хуки повторяются**: частоты из `hook_freq` плюс качественный разбор по `samples` (типовые формулы оффера, цены, позиционирование, районы).
5. **Долгожители (≥90 дней)**: 3–6 самых показательных с кратким описанием подхода. Оговорка: долгий показ — сильный сигнал, что объявление работает, но не гарантия. Бывают забытые кампании с малым бюджетом. Больше доверия, если у рекламодателя несколько вариантов креатива (`variants`) или свежие копии.
6. **Свободные места**: то, что почти никто не использует (низкие значения в `hook_freq`, отсутствие сайтов, редкие двери). Сформулируй 3–5 конкретных углов для отстройки клиента.
7. **Ограничения среза**: поиск только по тексту объявлений (часть рынка не попала), это снимок на сегодня, что исключено как шум.
8. **Дальше**: предложи повторный срез через 1–2 недели, разбор одного конкурента глубже, расширение запросов или CSV.

Отчёт пиши на языке пользователя. Ссылки на объявления делай в формате `https://www.facebook.com/ads/library/?id=<id>`.

## CSV (только по просьбе)

`window.__mai.csv()` возвращает CSV-строку (id, page, start, active, fmt, variants, cta, link, platforms, kws, title, body). Если подключена папка пользователя, сохрани CSV туда. Если строка очень большая (больше примерно 60 тыс. символов), сначала отфильтруй, например оставь только топ-рекламодателей, или выгружай частями через `.slice()`.

## Честные ограничения

- Данные публичные, но автоматический сбор противоречит условиям Meta. Работай деликатно: без логина, без обхода капчи, не больше ~15 запросов за прогон. Если появилась капча или вход, остановись и скажи пользователю.
- Для коммерческой рекламы вне ЕС Meta не показывает бюджеты и охваты. «Сила» рекламодателя видна только косвенно: число объявлений и длительность.
- Внутренняя структура ответов Meta меняется. Сборщик ищет любые узлы с `ad_archive_id`, поэтому обычно переживает изменения. Если поля массово пустые, проверь в консоли пример узла `Object.values(window.__mai.store)[0]` и поправь поля в `collect`.
- Не делай выводов о конкретных людях за пределами их рекламы. Отчёт касается бизнесов и их объявлений.
