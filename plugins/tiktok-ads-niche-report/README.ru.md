# tiktok-ads-niche-report

Скилл для Claude, который собирает рекламу конкурентов в **TikTok** и
превращает её в отчёт и набор готовых к тесту гипотез объявлений для
таргетолога: кто рекламируется, куда ведёт реклама, какие хуки и форматы
роликов повторяются, какие ролики крутятся дольше всего или масштабируются,
о чём не говорит никто и что изменилось с прошлого среза. Без платных API.

English version: [README.md](README.md) · Парный плагин для Facebook и
Instagram: [meta-ads-niche-report](../meta-ads-niche-report/skills/meta-ads-niche-report/SKILL.md)
(тот же репозиторий, тот же процесс).

## Два источника, и почему важна страна

У TikTok два публичных источника, и они сильно различаются:

| | **TikTok Ad Library** | **Creative Center → Top Ads** |
|---|---|---|
| Страны | Только ЕС/ЕЭЗ, GB, CH, TR (33 страны) | Украина, США и ещё около 30 |
| Что это | Вся реклама, показанная в стране (требование DSA) | Подборка топ-аукционных объявлений, которую делает сам TikTok |
| Поиск | По тексту объявления и имени рекламодателя (любое из слов или точная фраза) | По коду отрасли, плюс слова бренда или товара |
| Рекламодатели | Да (аккаунт TikTok, подписчики, страна) | Почти всегда скрыты |
| Сроки | Первый и последний показ → дни показа | Нет |
| Метрики | Диапазон охвата; в карточке: цель, CTA, ссылка, таргетинг (возраст, пол, города, интересы) | CTR-перцентиль в отрасли, лайки, уровень бюджета, длина ролика; в карточке: посадочная |

Источник выбирается по стране. **Для Украины и США аналога отчёта по
конкурентам, как у Meta, нет**: есть только Creative Center, и отчёт прямо
говорит, что показывает «что работает в отрасли», а не что делают ваши
конкуренты.

## Что получаете

- Кто рекламируется (аккаунт TikTok и подписчики), сколько дней шли
  объявления, охват, куда ведёт реклама (сайт, приложение, лид-форма, TikTok
  Shop, сообщения), цели, CTA и таргетинг.
- Хуки и цены, посчитанные по **уникальным роликам** (рекламодатели грузят один
  ролик десятки раз: 189 объявлений бывают 15 рекламодателями), с силой сигнала
  у каждого хука (strong / moderate / weak); копии ролика показаны как
  масштабирование.
- Ролики, нарезанные на раскадровки (хук 0–3 с, четверти, финал), и словарь
  тегов (тип хука, формат, лицо в первую секунду, текст поверх, CTA в финале).
- Посадочные страницы лидеров рядом с рекламой (обещано против страницы, цены,
  пиксели, скриншот на ширине телефона).
- Сравнение двух срезов: остановки (видны по дате последнего показа),
  масштабирование, выключенные молодые тесты, новые рекламодатели.
- 3–5 гипотез объявлений для клиента (хук первых 2 секунд, сценарий 15–30 с,
  текст до 100 символов, кнопка CTA TikTok), проверенных по правилам рекламы
  TikTok и подтверждённым фактам клиента, с планом теста.
- Excel и HTML одним файлом.

## Установка

**Claude Code** (терминал или вкладка Code в десктопном приложении). Либо:

```text
/plugin marketplace add YanisDigital/competitor-ads
/plugin install tiktok-ads-niche-report@meta-ads-niche-report
```

(маркетплейс сохранил имя первого плагина, чтобы не ломать уже выданные
команды установки), либо скопируйте
`plugins/tiktok-ads-niche-report/skills/tiktok-ads-niche-report/` в
`~/.claude/skills/tiktok-ads-niche-report/`.

**Чат claude.ai**: заархивируйте папку скилла (путь выше) и загрузите в
*Settings → Skills*. Так добавляется только скилл; для сбора нужен подключённый
браузер (встроенный браузер десктопного приложения или Claude in Chrome) либо
командная строка.

## Требования

- **Браузерный режим**: браузер, подключённый к сессии Claude. Для
  встроенного браузера десктопного приложения ничего ставить не нужно.
- **CLI, детали и проверка сайтов**: Python 3.10+ и Playwright:
  ```bash
  pip install playwright
  python -m playwright install chromium
  ```
  Creative Center не открывается в фоновом браузере, поэтому для этого
  источника открывается видимое окно (ничего не маскируется).
- **Остальное**: Node.js; для Excel ещё `pip install openpyxl`.

Ничего не устанавливается автоматически.

## Быстрый старт

Команды запускаются из папки скилла.

```bash
python scripts/scrape.py --preset fitness --country PL           # Ad Library
python scripts/details.py out/fitness-pl/<дата> --limit 40       # CTA, ссылка, таргетинг
python scripts/fetch_creatives.py out/fitness-pl/<дата>          # ролики → раскадровки
node scripts/export_html.js out/fitness-pl/<дата>
python scripts/export_xlsx.py out/fitness-pl/<дата>

python scripts/scrape.py --source cc --country UA --industry 14  # Creative Center
```

На практике достаточно попросить Claude: «что крутят в тиктоке по фитнесу в
Польше». Пресеты: `fitness`, `beauty`, `dentistry`, `auto-service`, `ecom-eu`,
`infobiz` (запросы на 10 языках, хуки ниши, слова-шум, сезоны).

Полный процесс, структура отчёта и правила гипотез: в
[SKILL.md](skills/tiktok-ads-niche-report/SKILL.md).

## Безопасность и приватность

- Сборщик читает только ответы, которые получают сами страницы TikTok: обе
  площадки подписывают запросы, прямых вызовов API нет.
- Посадочные страницы (проверка сайтов, только по просьбе) — чужой код: JavaScript
  страницы выключен по умолчанию, WebSocket запрещён, открываются только
  публичные адреса без логина и пароля, редиректы идут по одному шагу с проверкой
  каждого адреса до запроса, ссылки через трекеры рекламных кликов не
  открываются (клик засчитался бы в чужой кампании). Chromium Playwright
  работает без песочницы (она здесь не запускается): для рискованной работы
  используйте отдельную учётку ОС или виртуальную машину.
- Имя плательщика («paid by», может быть частным лицом) **не сохраняется**;
  остаётся только признак «плательщик отличается от рекламодателя». Старые
  срезы: `node scripts/scrub.js out/<ниша>`.
- Отчёты: весь чужой текст экранируется, скриптов нет (CSP), формулы в Excel и CSV
  обезвреживаются, ссылки на чужие сайты без `ttclid` и utm, бюджет и CPA клиента
  не попадают в HTML (флаг `--with-budget` добавляет их). `--no-images` собирает
  HTML без кадров роликов и скриншотов.
- Тексты объявлений, имена и посадочные страницы — недоверенный ввод для модели:
  собирайте данные с подтверждением команд.
- Собранные данные, брифы клиентов и отчёты остаются в `out/` (игнорируется git).

## Тесты

```bash
node --test tests/tiktok.test.mjs      # из корня репозитория
```

Логика на записанных ответах TikTok, проверка регулярок на зависание и проверка
SSRF (последней нужны Playwright и интернет, без них она пропускается).

## Ограничения

- Ad Library есть только для ЕС/ЕЭЗ, GB, CH и TR.
- TikTok не публикует бюджеты и показы: только диапазон охвата (Ad Library) или
  уровень бюджета и перцентиль CTR (Creative Center). «Сила» рекламодателя видна
  косвенно: по роликам, копиям и дням показа.
- Поиск видит только объявления со словами запроса; собирается верх каждой
  выдачи (по умолчанию 96 объявлений на запрос).
- Подписанные ссылки на видео и обложки живут часы–дни: креативы качайте сразу
  после сбора. Звук не анализируется.
- Страницы TikTok меняются; сборщик ищет объекты по ключам, а не по фиксированному
  пути. Если поля пустые, смотрите `references/troubleshooting.md`.
